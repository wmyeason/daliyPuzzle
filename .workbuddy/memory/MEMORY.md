# 日历拼图项目（daliyPuzzle）

Vue3 + TypeScript + Canvas 单页拼图游戏：按当天（或指定）日期，用 10 块碎片盖住背板上除「月份·日期·星期」三格外的所有格即胜。

## 已验证的核心设计
- 棋盘 8 行 × 7 列，**50 有效格**：row0/1 = 12 个月；row2-6 = 1-31 日；row6 c3-6 = 日一二三，**row7 c4-6 = 四五六**（row7 c0-3 为无效格，背板上不存在）。
- 基准碎片集（10 种、共 47 格，恰好 50-3）：`Z4`(2×2Z)、`T5`(3×3T)、`Z5a`(2×3Z)、`I4`(1×4竖条)、`L4`(3×1L)、`V5`(3×3L)、`Z5b`(3×2Z)、`L5`(4×1L)、`Q5`(2×3缺左上)、`U5`(2×3缺中下)。
- 用内置 **DLX 精确覆盖求解器** 求解参考解；已单独脚本验证 **2024-2026 全部 1096 个日期 0 失败**。

## 关键坑（别再踩）
1. solver 列重映射必须 **跳过无效格**（row7 c0-3）：否则这些列 S=0，`chooseCol` 选中后直接 `return false` → 全部 NOSOL。
2. `board.targetIndices` 的月份格必须用 `put()` 真实（行,列）建索引表，**不能写 `month-1`**——7-12 月月份格实际在 row1，会偏一格，导致 7-12 月日期不可解（实测 183 天失败）。
3. `isSolved` 兜底：每块覆盖格必须是「有效且非目标」，否则可能被盖住目标却误判通关。

## 代码结构（src/）
- `game/board.ts` 棋盘布局 + 目标格索引表
- `game/pieces.ts` 碎片形状库 + 旋转去重
- `game/solver.ts` DLX + 全部候选摆放 + `solveFor(目标)`
- `game/engine.ts` 游戏状态机（createGame / canPlace / isSolved / 旋转）
- `components/GameCanvas.vue` 木纹背板渲染 + 拖放吸附 + 右键旋转 + 提示/自动完成
- `App.vue` 顶栏（选日期/随机/重置/提示/自动）+ 玩法 + 图鉴 + 胜利弹层

## 运行
`npm install && npm run dev`（vite，端口 5173）。用户全局要求：**只生成代码，不编译运行**。
